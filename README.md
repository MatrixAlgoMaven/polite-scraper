# The Polite Scraper

A Python web-scraping project for learning how to fetch, extract, normalize, validate, and store book catalogue data responsibly.

## Target Classification

- **Target:** [Books to Scrape](https://books.toscrape.com/)
- **Purpose:** Practice web scraping on a public catalogue designed for learning.
- **Scope:** The first three catalogue pages only, covering 60 book listings.
- **Data collected:** Book title, product URL, price, availability, star rating, description, source catalogue page, and fetch timestamp.
- **Robots check:** On 16 October 2026, my browser request to `https://books.toscrape.com/robots.txt` returned HTTP 401 Unauthorized. I have recorded the observed result; I have not inferred the file's contents from that response.
- **Responsible use:** This project is limited to the practice sandbox. I will check the rules and terms before using similar code on another site.

I will not reuse this code on another site without checking its rules and terms first.
